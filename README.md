# SQL Airport System

A relational database design for an airport system (SQL Server / T-SQL): table definitions and sample data in `airport system.sql`.

It also includes:
- `Parallel Roro and JojoFinall/` - a small Flask web app (`app/app.py`, `template/index.html`) that runs parallel tasks (`alltasks.py`) through MPI. Paths in `app.py` are hard-coded for the original machine and need updating.
- `SQL ecommerce system/` - an e-commerce database project.

## Technologies
SQL (T-SQL), Python, Flask
